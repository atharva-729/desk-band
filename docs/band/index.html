How to play

  1. Click Start the band. Share this tab with its sound in the call (Meet: Present → A tab → "Also share tab audio").
  2. Everyone scans the code with their phone (or opens the link and types the room code), types a name and taps Start. Each person picks any free instrument (first come, first served); taken ones are blacked out.
  3. Phone flat on the table, tap the table right next to it. A tap counts if the phone hears it or feels it. Any tap plays; the band places it on the beat and picks notes that fit, so nothing sounds wrong.
  4. Wear headphones on your laptop, and don't join the call on the phone that's playing. Start slow, then speed up together.
Phones and this page talk through a free public relay (MQTT, –) using the room code. Phones send only "a knock, this strong", plus the name a player types: no audio leaves a phone and nothing is recorded. Each knock reaches this page about 0.2 s after it happens, so the band plays it on the next half-beat (arpeggiator: next beat). · How Desk Band works
